CLOUD SECURITY PROJECT

AWS IAM & KMS Security Architecture

A hands-on AWS security lab focused on identity and access management, encryption, conditional access, and least-privilege security controls.

PROJECT OVERVIEW

Security Objective

This project demonstrates how AWS IAM, Amazon S3, and AWS KMS can work together to enforce least privilege, separation of duties, secure access to cloud storage, and encryption controls across development and production environments.

SECURITY ARCHITECTURE

Identity and Access Design

Alice

Configured with development access and encryption permissions using a customer-managed AWS KMS key.

Beavis

Configured with development access, restricted production access, and decryption permissions using AWS KMS.

Key Takeaways
