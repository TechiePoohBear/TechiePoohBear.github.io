NETWORK SECURITY PROJECT

Home Network Security Architecture & Risk Assessment

A network security assessment documenting the devices, connectivity, security controls, and potential risks within a residential network environment containing personal, corporate, mobile, and IoT devices.

PROJECT OVERVIEW

Security Objective

The objective of this project was to map the devices connected to a residential network and evaluate the security considerations created by connecting work systems, personal devices, mobile devices, and IoT technology through a shared network infrastructure.

NETWORK ENVIRONMENT

Network Architecture

The environment used an Xfinity xFi Advanced Gateway (XB7) as the primary network gateway. Devices connected to the environment included work laptops, personal computers, smartphones, an iPad, a printer, smart entertainment devices, and a Ring camera.

Corporate Devices

Work MacBook systems, a work iPhone, and a work iPad were connected to the residential wireless network.

Personal Devices

Personal computing and mobile devices included a MacBook Air and personal iPhone.

IoT & Entertainment

Connected devices included a Ring camera, Fire TV, Samsung television, and network-connected printer.

Network Infrastructure

Internet connectivity was provided through an Xfinity xFi Advanced Gateway (XB7), which served as the central connection point for wireless devices.

SECURITY ASSESSMENT

Security Observations

Shared Network Environment

Corporate, personal, and IoT devices shared the same residential network environment, increasing the importance of understanding device trust and network boundaries.

Endpoint Protection

Work devices used organization-managed security controls, including endpoint protection, firewall configurations, and secure remote-access technologies.

IoT Exposure

Smart-home and entertainment devices introduce additional endpoints that should be considered when assessing the overall attack surface of a residential network.

Asset Visibility

Creating a network diagram provided visibility into the number and types of systems connected to the environment and helped identify relationships between network assets.

RISK REDUCTION

Recommended Security Improvements

Network Segmentation

Separate higher-risk IoT and smart-home devices from trusted personal and corporate systems where the network infrastructure supports segmentation or isolated networks.

Device Inventory

Maintain visibility into authorized devices connected to the network and periodically review the environment for unknown or unnecessary systems.

Endpoint Protection

Apply appropriate endpoint security controls, operating-system updates, and security configurations to supported personal computing devices.

Secure Network Configuration

Maintain strong wireless authentication, secure administrative credentials, firmware updates, and appropriate router security settings.

WHAT I LEARNED

Key Takeaways

This project helped me understand that network security begins with visibility. Mapping the environment allowed me to see how many different types of devices shared the same network and how corporate, personal, and IoT systems can introduce different levels of risk. I also learned how asset inventory, endpoint security, network segmentation, and secure network configuration can work together to reduce the attack surface of a residential environment.
