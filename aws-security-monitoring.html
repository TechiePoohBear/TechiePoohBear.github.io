CLOUD SECURITY

AWS Security Monitoring & Logging

A cloud security monitoring project focused on implementing logging, visibility, and event monitoring within an AWS environment using AWS CloudTrail and Amazon CloudWatch.

AWS CloudTrail CloudWatch Security Monitoring Cloud Security

PROJECT OVERVIEW

Security Objective

The objective of this project was to explore how AWS logging and monitoring services can provide visibility into activity occurring within a cloud environment. The lab involved configuring and examining AWS monitoring capabilities to understand how security-relevant events can be recorded, reviewed, and used during security investigations.

TECHNOLOGIES

AWS Services Used

AWS CloudTrail

Used to record AWS account activity and provide an audit trail of actions performed within the cloud environment.

Amazon CloudWatch

Used to support monitoring and visibility into activity occurring within AWS resources and services.

SECURITY WORKFLOW

Monitoring Approach

The project demonstrated a basic cloud security monitoring workflow: generate activity within the AWS environment, capture relevant events through AWS logging services, review the resulting records, and analyze the information from a security perspective.

SECURITY VALUE

What This Demonstrates

This project demonstrates hands-on exposure to cloud logging, auditability, security monitoring, and event analysis. It also reinforces the importance of maintaining visibility into administrative and resource activity when protecting cloud environments.
