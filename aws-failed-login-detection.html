CLOUD SECURITY

AWS Failed Console Login Detection & Alerting

Built and validated an AWS security detection workflow that identifies failed Management Console login attempts and generates automated security alerts using CloudTrail, CloudWatch, and Amazon SNS.

AWS CloudTrail CloudWatch Amazon SNS Detection Engineering Cloud Security

PROJECT OVERVIEW

Security Objective

The objective of this project was to build and validate a cloud-based detection mechanism capable of identifying failed AWS Management Console authentication attempts. CloudTrail events were forwarded to CloudWatch Logs, evaluated using a metric filter, and converted into a custom security metric that could trigger an automated alert.

TECHNOLOGIES

AWS Services Used

AWS CloudTrail

Captured AWS account activity and recorded Management Console authentication events used by the detection workflow.

Amazon CloudWatch Logs

Received CloudTrail events and provided centralized log data for security monitoring and detection.

CloudWatch Metric Filter

Filtered CloudTrail log events for failed ConsoleLogin activity and generated the custom FailedConsoleLoginCount metric.

CloudWatch Alarm

Monitored the custom failed-login metric and entered the ALARM state when the configured threshold was reached.

Amazon SNS

Delivered an automated email security notification when the CloudWatch alarm was triggered.

SECURITY WORKFLOW

Detection & Alerting Workflow

Failed AWS Management Console login attempts are captured by CloudTrail and delivered to CloudWatch Logs. A metric filter identifies matching failed-login events and increments the custom FailedConsoleLoginCount metric. When the metric reaches the configured threshold, the CloudWatch alarm enters the ALARM state and invokes Amazon SNS to send an automated email security alert.

CloudTrail → CloudWatch Logs → Metric Filter → Custom Metric → CloudWatch Alarm → Amazon SNS → Email Security Alert
